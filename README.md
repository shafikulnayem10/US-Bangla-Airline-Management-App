# ✈️ US-Bangla Airline Management App

A desktop-based airline management system built using **C#, .NET Framework, and Windows Forms**, designed to simulate real-world airline operations with role-based access and modular architecture.

---

## 🎯 Project Goal

The goal of this project was to design and implement a **complete airline management system** that handles:

- Flight scheduling and management  
- Ticket booking and seat allocation  
- Customer management with loyalty programs  
- Payment processing and tracking  
- Role-based system access  

This project demonstrates how complex real-world systems can be modeled using **Object-Oriented Programming (OOP)** principles.

---

## 🧠 System Overview

The application follows a **role-based architecture**, where each user type interacts with the system through specific permissions and features.

It simulates real airline workflows such as:
- Booking lifecycle management  
- Flight updates affecting multiple users  
- Loyalty-based upgrades and benefits  
- Staff-assisted ticket operations  

---

## ✨ Key Features

- ✈️ Flight creation, update, and cancellation  
- 🎟️ Ticket booking and seat allocation  
- 👥 Multi-role system (Admin, Customer, Staff)  
- 💳 Payment tracking and management  
- ⭐ Loyalty points and premium upgrade system  
- 🔐 Role-based authentication and authorization  
- 🖥️ Desktop-based interactive UI  

---

## 👥 User Roles & Capabilities

### 🔑 Admin
- Manage flights, aircraft, and routes  
- View all bookings, customers, and payments  
- Cancel flights with automatic system updates  
- Full system control and monitoring  

---

### 👤 Normal Customer
- Register and log in  
- Search flights by destination, date, and class  
- Book and cancel tickets  
- Earn **loyalty points per booking**  

---

### ⭐ Premium Customer
- Auto-upgrade after reaching loyalty threshold  
- Receive **discounts on bookings**  
- Priority seat selection  
- Extra baggage allowance  
- Redeem points for services and tickets  
- Subject to loyalty expiry and downgrade rules  

---

### 🎟️ Ticket Counter Staff
- Book tickets on behalf of customers  
- Assist in offline booking scenarios  
- Generate/print ticket copies

## 🧠 How It Works (Technical Breakdown)

- Implemented **OOP principles** (Encapsulation, Inheritance, Polymorphism)  
- Designed **role-based access control** for different user types
